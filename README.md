# PsychoVector

Платформа для психологических тестирований.

## Как запустить

1. Установи [Node.js](https://nodejs.org/)
2. Скачай этот репозиторий
3. Открой терминал в папке проекта
4. Напиши: `npm install`
5. Напиши: `node server.js`
6. Открой в браузере: http://localhost:3000
